# 智能书签管理系统

前后端分离的书签管理工具。分类树拖拽排序、JSON/HTML 导入导出、浏览器书签兼容。

## 快速开始

```bash
nix-shell
just build
just start-all
# 打开 http://localhost:5173
# 账号: admin / 123456
```
